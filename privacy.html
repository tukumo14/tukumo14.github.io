DEVLOG UPLOADER

プライバシーポリシー

制定日：2026 年 11 月 23 日

1. このツールについて

「devlog uploader」（以下「本ツール」）は、制作者本人が、自分の YouTube チャンネルに ゲームの開発記録動画を投稿するためだけに使う個人用のツールです。制作者以外の人は利用しません。

2. 取得する情報と使い道

本ツールは、制作者本人が Google のログイン画面で許可した範囲で、YouTube Data API を通じて次のことを行います。

  • 動画のアップロードと、タイトル・説明・タグの設定
  • 投稿先のチャンネル名の確認
  • 制作者が自分で上げた動画の削除（作り直した動画との差し替えのため）

これ以外の目的には使いません。ほかの人のアカウントや動画の情報は扱いません。

3. 保存と管理

Google から受け取った許可の情報（アクセストークン）は、制作者のパソコンの中だけに保存します。 外部のサーバーには送りません。

4. 第三者への提供

取得した情報を第三者に提供・販売することはありません。

5. Google の規約への準拠

本ツールによる Google API から受け取った情報の利用は、 Google API サービスのユーザーデータに関するポリシー （「限定的な使用」の要件を含む）に従います。 YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

6. 許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。

Privacy Policy (English summary)

devlog uploader is a personal tool used only by its developer. With the developer's own consent, it uses the YouTube Data API to upload videos (and set their title, description and tags), read the developer's channel name, and delete videos the developer previously uploaded. Access tokens are stored only on the developer's computer and are never sent to any other server, shared, or sold. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: note.com/watawata_14.
